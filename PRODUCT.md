# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primary users are creators operating an AI influencer studio. They use the product to define personas, create media, manage voice and appearance, and ask an agent to coordinate multi-step creative work. This is inferred from the implemented workflows and the current redesign brief.

## Product Purpose

AI Influencer Studio brings persona creation, media generation, editing, research, planning, and multi-step agent execution into one workspace. Success means a creator can describe an outcome in plain language, review proposed work when needed, and receive usable saved results without coordinating each tool manually.

## Positioning

The Super Agent can turn one creative brief into an inspectable plan that invokes the studio's own persona, research, image, video, voice, editing, and library capabilities.

## Operating Context

Creators move between persona setup, content generation, editing, chat, trends, the library, and content planning. Super Agent projects retain briefs and conversation history. Some plans run in the background, some require review, and generated results are saved into the studio library.

## Capabilities and Constraints

- The Super Agent supports projects, saved project briefs, attachments, research, persona selection, voice interaction, model selection, plan review, background execution, recovery, and media previews.
- The interface must remain usable on mobile and desktop web.
- Potentially consequential plans preserve an explicit review or approval state.
- Advanced settings remain available without competing with the primary prompt workflow.

## Brand Commitments

- Product name: AI Influencer Studio.
- The application uses a dark charcoal and warm gold visual identity.
- The Super Agent contains no blue hues and feels consistent with the rest of the studio.
- The experience feels focused and premium rather than crowded.

## Evidence on Hand

- Existing production application and source implementation.
- Existing persona, media, voice, research, planning, and agent execution workflows.
- No testimonials, customer claims, or performance benchmarks are available.

## Product Principles

- Start with the creator's intended outcome, then reveal implementation detail only when useful.
- Keep powerful controls available without competing with the main creative act.
- Make plans, execution state, and saved results understandable and recoverable.
- Preserve continuity across projects, personas, conversations, and generated assets.

## Accessibility & Inclusion

Use semantic controls, visible focus states, readable contrast, keyboard-accessible menus, and responsive layouts.
